# Project: Light-Story Monorepo

## Tech Stack
- **Frontend**: Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS 4, Ant Design v5 (`@light-story/ui`)
- **Backend / Workers**: Cloudflare Workers (Node16 module), Cloudflare Pages, Supabase (Postgres, Auth, Realtime, Storage)
- **CI/CD**: GitHub Actions, npm scripts, monorepo root installation
- **Languages**: TypeScript (ES2022 target), JavaScript (Node16)

## Commands
- **Build**: `npm run build` (runs in each package)
- **Test**: `npm test` or `npm run test` (Vitest)
- **Lint**: `npm run lint`
- **Format**: `npm run format`
- **Type‑check**: `npm run typecheck`
- **Dev server**: `npm run dev` (frontend)
- **Supabase CLI**: `supabase start`, `supabase db push`

## Code Conventions
- Use **named exports** only; avoid default exports.
- Place tests alongside source files (e.g., `src/foo.ts` → `tests/foo.test.ts`).
- Keep utilities in `packages/sdk` or `packages/ui` and import via `@light-story/sdk` / `@light-story/ui`.
- For UI components, use Ant Design (`@light-story/ui`) only in admin routes; public routes use Tailwind + Radix UI.
- Write **pure, in‑process** utilities without runtime I/O unless explicitly required.
- Export read‑only types where appropriate (e.g., `export type IssueStore = ReadonlyMap<string, Issue>`).

## Boundaries
- **Never** commit `.env` files, secrets, or any credentials.
- **Never** add runtime dependencies to packages intended to be pure utilities.
- All `npm install` operations must be performed at the monorepo root.
- Server actions must verify `requireActionRole(ACTION_ADMIN_ROLES)` and validate inputs with Zod.
- Tests must be run locally before any commit (`npm test`).

## Patterns
- Use Zod for schema validation.
- Use `cn()` utility for conditional classNames in UI components.
- For data fetching in workers, use Cloudflare Workers AI bindings where appropriate.
- Defensive copying: always clone input objects before mutating.

## Known Gotchas
- ESLint `parserOptions.project` must include test files.
- Ant Design is scoped to admin routes; importing it in public routes will cause bundle bloat.
- Ensure `module` is set to `Node16` when using `moduleResolution: node16`.
- Avoid duplicate React instances by installing dependencies only at the repo root.
