# @light-story/ui

Ant Design v5 design system and enterprise Admin CMS UI SDK for Light-Story.

## Features
- **Branded Design Tokens**: Orange primary (`#f97316`) and slate dark mode synchronized with Light-Story theme.
- **Next.js 16 App Router SSR**: Style extraction via `AntdRegistry` preventing flash of unstyled content.
- **Composite Admin Components**: `AdminTable`, `MetricCard`, `FormModal`, and `FilterBar`.
- **Curated AntD Primitives**: Re-exported enterprise primitives for seamless, consistent development.
